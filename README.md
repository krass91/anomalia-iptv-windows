# Anomalia IPTV Player for Windows

Преносим IPTV плеър за Windows, базиран на libVLC. Без инсталация — само един EXE файл.

## Функции

- **M3U / Xtream Codes / Stalker портали** — зарежда всякакви доставчици
- **4 екрана едновременно** — гледай различни канали на един монитор
- **Цял екран** — автоматично скриване на бутоните след 5 секунди
- **EPG (телевизионна програма)** — поддръжка на XMLTV
- **Архив / Catch-up** — гледане на изминало съдържание
- **Любими канали**
- **Субтитри и аудио писти**

## Изтегляне
